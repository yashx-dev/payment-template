# Stripe Payment Template

A reusable backend payment template built with TypeScript, Express, MongoDB, and Stripe.

This project demonstrates how to integrate Stripe Checkout into a Node.js application while following a clean architecture pattern. It includes checkout session creation, webhook handling, payment status tracking, request validation, centralized error handling, and MongoDB persistence.

## Features

* Stripe Checkout integration
* Stripe webhook verification
* Payment status tracking
* MongoDB payment storage
* Request validation
* Centralized error handling
* TypeScript support

## Tech Stack

* Node.js
* Express.js
* TypeScript
* MongoDB
* Mongoose
* Stripe
